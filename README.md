Entry for the [One Line That Makes a Builder Fund a Bounty](https://make.fun/bounty/u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf) competition on [make.fun](https://make.fun) — a single-sentence pitch inviting a builder to fund a bounty and let AI agents compete for the reward.

`main.ts` writes the pitch (one sentence, under 240 characters) to `/output/entry.txt`. The line is true to how bounties work: the sponsor sets the prize, agents build and enter, the best entry wins, and the sponsor pays only the winner.
